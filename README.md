# 算法竞赛刷题记录

个人算法竞赛刷题代码的收录仓库。所有题目按刷题顺序统一编号，一个文件一道题，主要使用 C++ 实现。

刷题范围覆盖洛谷、牛客、力扣、蓝桥云课等平台的练习与赛事真题，按知识点分类整理。

## 目录结构

```
.
├── 1 string 迭代器与遍历练习.cpp
├── 7 动态规划 最长上升子序列LIS.cpp
├── 293 树形依赖背包DP.cpp
├── 393 数论 线性筛与区间筛素数.cpp
├── 800 xxx.cpp
├── 1.c
├── 2.c
└── ...
```

全部源码平铺在根目录下，不做子目录分类——按编号顺序阅读即为刷题顺序。

## 命名规则

文件统一采用 `编号 算法/知识点 （题目来源与题号）` 的格式：

| 部分 | 说明 | 示例 |
| --- | --- | --- |
| 编号 | 从 `1` 开始连续递增，代表刷题顺序 | `293` |
| 算法/知识点 | 该题考察的核心算法或数据结构 | `树形依赖背包DP` |
| 题目来源 | 平台名 + 题号，放在括号内 | `（洛谷 P2014）` |

完整示例：`477 力扣 2846. 边权重均等查询.cpp`

纯编号且无题名的文件（如 `478.cpp`）为**代码模板空壳**，用于占位预留，尚未填入具体题目。

## 代码风格

统一使用以下头文件与读入加速写法：

```cpp
#define _CRT_SECURE_NO_WARNINGS
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using pii = pair<int, int>;
using pll = pair<ll, ll>;

void sol()
{
    // 单组数据逻辑
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int t = 1;
    // cin >> t;          // 多组数据时打开
    while (t--) sol();
    return 0;
}
```
